## Sobre o Projeto
O SIGE é uma aplicação web desenvolvida para centralizar o gerenciamento de eventos acadêmicos. O sistema permite o cadastro, listagem, edição e exclusão de eventos e participantes, além de realizar o registro e cancelamento de inscrições. O projeto foi construído utilizando PHP puro, HTML, CSS e MySQL, aplicando conceitos fundamentais de CRUD e Programação Orientada a Objetos.

## Como Executar

1. Abra o arquivo `classes/Conexao.php` e ajuste as variáveis de conexão (host, usuário, senha) de acordo com o seu ambiente local.
2. Execute o script `database/ddl.sql` no seu gerenciador de banco de dados (como phpMyAdmin) para criar o banco e as tabelas.
3. Inicie o seu servidor local (Apache via XAMPP, WAMP, ou outro) e acesse o diretório do projeto pelo navegador (exemplo: `http://localhost/sige/index.php`).
